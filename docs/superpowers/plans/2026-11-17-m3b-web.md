# M3b — Web Paneli: Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** M3a API'sinin üstünde güvenli, erişilebilir, canlı güncellenen bir React paneli (Giriş, Genel bakış, Cihaz listesi, Cihaz detayı + grafikler, Cihaz ekle).

**Architecture:** `packages/protocol` zod şemaları tek sözleşme kaynağı (ön yüz çalışma zamanında doğrular, backend sözleşme testleriyle kilitlenir, OpenAPI üretilir). `apps/web` Vite+React SPA, dev'de `/api` proxy (aynı köken). TanStack Query sunucu durumu; SSE olayları önbelleğe yazılır. Gerçek backend ile Playwright E2E.

**Tech Stack:** React 19, Vite, TypeScript strict, TanStack Query, React Router, Tailwind v4, shadcn/ui (Radix), Inter (değişken, `@fontsource-variable/inter`), Phosphor ikonları, uPlot, Vitest + Testing Library, Playwright (`channel: "chrome"`) + `@axe-core/playwright`.

**Spec:** `docs/superpowers/specs/2026-11-17-m3b-web-design.md` (ChatGPT onaylı). Backend: M3a (`docs/ilerleme/M3a.md`).

## Global Constraints
- Dal: `feat/m3b-web`. Her görev ayrı commit; **push yok**; `feat/m1-agent` dokunulmaz.
- **Backend sözleşmesi tek eklemeyle değişir: `GET /api/v1/devices/:id/metric-names` (Görev 2).** Başka API değişikliği yok; ön yüz yalnız sözleşme testiyle kilitli şekilleri kullanır.
- **Testler sahte API ile yeşil geçemez:** E2E gerçek API süreci + geçici TimescaleDB + Vite + makinedeki Chrome kullanır. Bileşen/birim testlerinde ağ sahte olabilir ama her ekran için en az bir gerçek-backend E2E senaryosu zorunlu.
- Ön yüzde token/sır yok; `fetch(..., {credentials:"same-origin"})`; `dangerouslySetInnerHTML` yasak (lint kuralı); cihaz adı/`device_info` metin olarak basılır.
- Durum = renk + ikon + metin (renk tek başına gösterge değil); WCAG AA; `prefers-reduced-motion`; dokunma hedefi ≥ 44 px mobilde; arayüz Türkçe.
- Grafik: boş kovada nokta yok → çizgi **kesilir** (interpolasyon yok); klavye alternatifi (aralık + yakınlaştır düğmeleri) ve veri tablosu görünümü.
- Playwright tarayıcı **indirmez** (`channel: "chrome"`); indirme gerektiren adım olursa durup sor.
- Her yeni bağımlılıktan sonra `pnpm license-scan` geçmeli (`-r` ile, 0 izinsiz).
- Güvenlik/sözleşme testleri **mutasyonla** doğrulanır (kodu boz, testin kırıldığını gör, geri al).
- Doğrulama: `pnpm -r --if-present test`, `pnpm -r --if-present lint`, `pnpm license-scan`, `pnpm --filter @sysmon/web e2e`; kapanışta C# Debug/Release de koşulur (değişmemeli). Docker Desktop kapalıysa başlat; DB: `docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d --wait`.
- Türkçe yorum/mesaj stili korunur. Windows/bash tuzakları: çok satırlı `node -e`/`sed` yerine Edit/Write kullan.

## Review Focus
1. Oturum yok/iptal/süre dolmuş → her korumalı ekran girişe yönlendirir, hedef sayfa korunur; 403/404 ekranları org/varlık ipucu vermez.
2. API yanıtı sözleşmeye uymazsa ön yüz sessizce bozulmaz: açık hata ekranı (`ContractError`), asla `undefined` göstermez.
3. SSE kopunca: bant görünür, yoklamaya düşer, yeniden bağlanınca bant kalkar ve veri akışı sürer; oturum iptal edilince SSE `closed` → girişe.
4. Grafik: boşluklu/NULL/tek noktalı/boş seri çökmez, sahte nokta üretmez; çok uzun aralık (30 gün) ve dar ekran (320 px) okunur.
5. Cihaz adı/`device_info`'da `<script>`, çok uzun metin, bidi/emoji → bozmadan metin olarak görünür (XSS yok, düzen kırılmaz).
