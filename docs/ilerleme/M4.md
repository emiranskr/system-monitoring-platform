## 2. G3 güvenlik özeti (ChatGPT zorunlu eklemeleri)
- Protokol: ikili, LE, uzunluk sınırı gövde okunmadan/bellek ayrılmadan; bozuk/kesik/çoklu/yinelenen/bilinmeyen/NaN/Inf/aralık dışı → reddedilir ve bağlantı düşer.
- Pipe: ACL'in **canlı** güvenlik tanımlayıcısı testle doğrulanır (yalnız beklenen SID + SYSTEM, `CreateNewInstance` yok); yetkisiz kimlik OS tarafından reddedilir; ad kapma (squatting) → sunucu başlamaz; istemci, protokolden ÖNCE `GetNamedPipeServerProcessId == süreç handle PID` doğrular, yanlışsa tek bayt yazmadan kapatır; sunucu da beklenen istemci PID'sini (ebeveyn) doğrular.
- Zaman aşımı/protokol/IO hatası bağlantıyı kapatır: geç gelen yanıt sonraki isteğe karışamaz.
- Süreç: shell yok, PATH yok, mutlak yol, Job Object `ACTIVE_PROCESS=1` (çocuk süreç engeli, gerçek süreç testiyle kanıtlı: kontrol Job dışında çocuk çalışıyor) + `KILL_ON_JOB_CLOSE` (Dispose/agent ölümü → yardımcı ölür), ebeveyn çıkınca yardımcı kendiliğinden çıkar.
- Watchdog: tek uçuş; takılan yardımcı öldürülür ve çıkışı doğrulanmadan yenisi başlatılmaz; üstel geri çekilme + tavan; devre kesici + tek yarı-açık deneme; yalnız ardışık 3 sağlıklı okuma hata sayacını sıfırlar; `ReadAsync` yardımcı arızasında asla fırlatmaz (agent CPU/RAM/GPU izlemesi etkilenmez).

## 3. Sınırlar / doğrulanmayanlar (kapatılmış DEĞİL)
- **Gerçek LibreHardwareMonitor yok** (sürücü/yönetici/UAC gerektirir; bu makinede HVCI çalışıyor → engellenebilir). Üretim yardımcısı yalnız `NullSensorProvider`; gerçek LHM ayrı, kullanıcı onaylı kapı. Pipe güvenlik testlerinin geçmesi LHM'nin güvenli çalıştığını KANITLAMAZ.
- **PIPE_REJECT_REMOTE_CLIENTS** testle doğrulanamadı: .NET `NamedPipeServerStream` Windows'ta bunu varsayılan ayarlar ama bayrak sorgulanamaz; uzak istemci testi bu ortamda güvenli/uygulanabilir değil (belgeli sınır).
- `FILE_FLAG_FIRST_PIPE_INSTANCE`: `maxInstances=1` ile aynı etkiyi verdiğinden bayrak tek başına mutasyonla ayırt edilemiyor (savunma katmanı; eşdeğer mutasyon).
- Yardımcı exe doğrulaması (TOCTOU): kontrol ile başlatma arasında pencere var; koruma, kurulum dizininin yönetici yazımlı olmasına dayanır (Program Files). Kurulum/izin düzenlemesi M6 (installer) işidir; geliştirmede `requireSecurePermissions:false`.
- Job'a atama süreç başladıktan hemen sonra (kısa pencere); yardımcı bizim kodumuz.
- `SensorSupervisor` henüz **Agent.Service'e bağlanmadı** (collector/metrik entegrasyonu G4); GPU/sensör metrikleri henüz sunucuya/UI'ya akmıyor.
- NVML UUID ↔ PDH LUID eşlemesi çözülmedi (PDH sağlayıcısı M4 dışı). Hibrit dizüstü ve GPU'suz VM profilleri doğrulanmadı.
- **Aralıklı test notu:** tam Release paketinde bir kez 1/358 test kırıldı (ilk soğuk koşu, hangisi olduğu yakalanamadı); sonraki 16 Release ve 1 Debug (373/373) koşusu yeşil. Zamana duyarlı yeni testler (pipe/supervisor/süreç) paralel yükte şüpheli; bağımsız incelemede ve G4'te yeniden izlenecek.
