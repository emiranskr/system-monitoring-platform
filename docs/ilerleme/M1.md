# M1 — Windows Monitoring Agent: KISMEN TAMAMLANDI (milestone kapatılmadı)

Tarih: 2026-11-11 · Dal: `feat/m1-agent`

## Tamamlanan işler (testli)
- **A1 Collector'lar** (`Agent.Collectors`): CPU (PDH `PdhAddEnglishCounter`, Türkçe Windows'ta çalıştığı doğrulandı), bellek (`GlobalMemoryStatusEx`), disk (`DriveInfo`), ağ (bayt farkı → bps; sayaç geri giderse yeniden baseline). `CollectorRunner`: hata ve zaman aşımı izolasyonu, iptal yok sayan collector'a sert zaman aşımı, geçersiz metrik adı reddi (protokol regex'iyle aynı).
- **A2 Spool** (`Agent.Transport/Spool.cs`): JSON-lines segmentleri + atomik durum dosyası; `(epoch, seq)` kalıcı; 24 sa **ve** bayt sınırı; yarım yazılmış satır atlanır; bozuk durumda yeni epoch (eski batch'ler korunur); ack yeniden başlatmada kalıcı.
- **A3 Uploader**: stop-and-wait, gzip + Bearer, cihaz kimliği gövdede yok, `ack_seq < seq` ise silme yok, kalıcı ret (200 + `rejected`) kuyruğu tıkamaz, 401/403'te durur, 409 saat sapmasında `server_time` ile ofset öğrenir, jitter'lı üstel backoff (tavan 5 dk), loopback dışı HTTP kurucuda reddedilir. **Gerçek HTTP sunucusuyla (HttpListener) test edildi.**
- `SamplingPipeline` + `AgentWorker`: collector → spool, `--server/--token-file/--data-dir` seçenekleri; iptalde kalan örnekler kaybolmadan yazılır.
